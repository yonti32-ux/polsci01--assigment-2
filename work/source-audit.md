# Source audit for chapters 4–7

Checked 2026-11-21. This is a targeted audit of the tools and quantitative claims in Yonatan's chapters, not an independent verification of every historical claim in chapters 1–3.

| Claim or source | Evidence and action |
|---|---|
| Digital humanities market figures | The [public report page](https://www.futuredatastats.com/digital-humanities-market) did not substantiate the quoted dollar values or their calculation. Removed those figures and retained an explicit limitation on financial market sizing. |
| Seshat release and access | The [official data page](https://seshatdatabank.info/data) confirms Polaris-2026, snapshots, replication datasets and API access. Removed unverified polity counts; release-specific coverage must be checked during the proposed project. |
| Pleiades | The [project website](https://pleiades.stoa.org/) confirms the gazetteer, reusable data and attribution licensing. Removed the unsupported current place count. |
| Perseus / Scaife | The live viewer blocked automated access. The [official project repository](https://github.com/scaife-viewer/scaife-viewer) confirms its reading-environment role. Removed corpus totals that were not independently verified. Added a repository citation. |
| dMGH | The [official description](https://www.mgh.de/en/digital-mgh/dmgh) supports digitized editions and the two-year moving wall. |
| openMGH | The [official description](https://www.mgh.de/en/digital-mgh/openmgh) supports TEI-XML and CC BY 4.0. Software and individual text/translation licenses must be distinguished. |
| ORBIS scale | The [Stanford project paper](https://orbis.stanford.edu/orbis2012/ORBIS_v1paper_20120501.pdf) supports the approximate road-network scale. Its earlier historical focus remains a limitation. |
| Ithaca | The [Nature paper](https://www.nature.com/articles/s41586-022-04448-z) supports the cited restoration comparison (about 62% model, 25% humans, 72% combined). These results concern inscription restoration, not accuracy on this project's classification task. |
| Flagship paper | The [open article](https://pmc.ncbi.nlm.nih.gov/articles/PMC9232109/) confirms publication identity. A detailed historical and methodological audit of chapter 3 remains with the authors; the proposed small study is not equivalent in scale. |
| Decision matrix | Scores recomputed as 2.60, 3.65 and 4.40. Sensitivity simulation has 9,960 / 38 / 2 wins, not a literal 99.6% / 0.4% split between only two alternatives. Analytic crossover is 0.60; first losing grid point is 0.61. |
| Proposed budget | Planning assumptions, not observed costs or supplier quotes: 96,300 NIS subtotal; 110,745 including 15% reserve. Cash requirement excluding donated researcher time: 22,425 including reserve. |

The comparison charts use team-assigned ordinal scores. The proposed study's high scores are design targets, not measured results. No market data, historical measurements or completed research results were fabricated to fill gaps.
