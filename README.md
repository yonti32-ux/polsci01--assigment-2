## על הפרויקט

האם קבלת הנצרות החלישה את האימפריה הרומית? הוויכוח הזה התחיל כבר ב-410, כשהוויזיגותים בזזו את רומא, והוא נמשך מאז דרך אוגוסטינוס ואדוארד גיבון ועד ההיסטוריונים של היום.

הדוח מציע מחקר שבודק את השאלה בדרך חדשה: משווים שלוש מדינות נוצריות שהגיעו לתוצאות שונות לגמרי:

- **רומא המערבית** – נפלה ב-476.
- **רומא המזרחית** – אותה דת, ושרדה עוד כאלף שנה.
- **הממלכה הפרנקית/הקרולינגית** – נוצרית כמעט מהקמתה, והתחזקה בזכות הברית עם הכנסייה.

**שאלת המחקר:** האם הנצרות פעלה ככוח שמחליש או שמחזק מדינות בין המאה ה-4 למאה ה-9, ומה קבע לאיזה כיוון היא פעלה?

**ההשערה המרכזית:** הדת עצמה לא הכריעה. מה שהכריע הוא מידת ההשתלבות בין הכנסייה לבין מוסדות המדינה.

**השיטה המוצעת:** מאגר נתונים השוואתי + ניתוח של אלפי טקסטים עתיקים בעזרת AI, עם תיקוף אנושי.

בהתאם להנחיות המטלה, את המחקר עצמו לא מבצעים. התוצר הוא הדוח המכין (כ-40 עמודים) לפי חלק א' של החוברת "מהבעיה אל ה-PDF".

## איך מפיקים את ה-PDF

**דרישות:** MiKTeX עם LuaLaTeX ו-biber, Python 3 עם matplotlib, PowerShell 7.

```powershell
# 1. יוצרים את הגרפים
python code/make_figures.py   # דורש matplotlib 3.10 ומעלה לעברית תקינה

# 2. מקמפלים (ארבע הרצות עד למסמך יציב)
lualatex main.tex
biber main
lualatex main.tex
lualatex main.tex
```

בהרצה הראשונה MiKTeX עשוי לבקש להתקין ספריות חסרות – מאשרים Install.

## איך עובדים יחד

1. **לפני שמתחילים:** `git pull`.
2. **כל אחד עובד על הפרקים שלו** – ככה לא דורכים זה על זה.
3. **אחרי כל שלב:** מקמפלים, בודקים שה-PDF תקין, ורק אז `git commit` ו-`git push`.
4. **הודעות commit ברורות:** למשל `ch03: add literature matrix`.
5. **לא מעלים קבצי ביניים** (`.aux`, `.log`, `.bbl` וכו') – הם ב-`.gitignore`.
6. **שינוי עיצובי שחוזר** – מתקנים בתבנית (`template.cls`), לא בתוך הפרק.

## שימוש ב-AI

הדוח הופק בשיטת Vibe Coding, כפי שנלמד בקורס:

- **כתיבה:** טיוטות הפרקים נכתבו בעזרת Claude, ונערכו ונבדקו על ידי הצוות.
- **ועדת סוכנים לבדיקה:** סוכן כותב, סוכן מבקר (צוות אדום) וסוכן בודק – לעברית-אנגלית, למקורות ולעיצוב.
- **מקורות:** כל מקור ברשימה נבדק ידנית שהוא קיים ושהוא אומר את מה שמיוחס לו.
- **איורים:** כל האיורים נוצרו בקוד (TikZ ו-Python). לא נעשה שימוש בתמונות עם זכויות יוצרים.
